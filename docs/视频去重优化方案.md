## 问题分析

### 原有去重逻辑的问题

根据日志分析（103个场景 → 21个去重后），原有的固定分组去重方法存在两个核心问题：

#### 1. 重要页面被丢失
**原因**：
- 使用固定的`group_size`（如5）机械地将连续场景分组
- `scene_001-005`强制归为一组，即使它们可能是完全不同的内容
- 只保留每组的"最后一帧"，假设最后一帧内容最完整

**实际情况**：
```python
# 旧逻辑
coarse_theme_group = (scene_number - 1) // group_size
# scene_001-005 → group_0
# scene_006-010 → group_1
# 每组只保留最大帧号的截图
```

**问题示例**：
- scene_001: 标题页（重要）
- scene_002: 目录页（重要）
- scene_003-005: 同一页的微小变化
- 结果：只保留scene_005，丢失了标题页和目录页

#### 2. 仍有重复内容
**原因**：
- 固定分组无法识别跨组的相似内容
- 如果同一页面的变化跨越了分组边界（如scene_005和scene_006），会被保留为两张截图

## 改进方案：基于图像相似度的智能去重

### 核心思路

1. **使用感知哈希（pHash）计算图像相似度**
   - 对图像内容进行哈希，而非依赖场景编号
   - 相似的图像哈希值接近，不相似的差异大

2. **动态分组而非固定分组**
   - 根据图像实际相似度动态归组
   - 相似度高的图像（哈希距离 < threshold）归为一组

3. **保留最清晰的帧而非最后一帧**
   - 使用Laplacian方差计算图像清晰度
   - 每组保留清晰度最高的图像

4. **最小间隔过滤**
   - 避免保留过于密集的截图
   - 确保相邻保留的截图之间至少间隔N个场景

### 技术实现

#### 1. 感知哈希计算

```python
def calculate_perceptual_hash(image_path, hash_size=16):
    """
    计算图像的感知哈希（pHash）。
    
    Args:
        image_path: 图像文件路径
        hash_size: 哈希大小，越大越精确但计算越慢
    
    Returns:
        imagehash.ImageHash对象，如果失败返回None
    """
    try:
        img = Image.open(image_path)
        phash = imagehash.phash(img, hash_size=hash_size)
        return phash
    except Exception as e:
        print(f"WARNING: Failed to calculate hash for {image_path}: {e}", flush=True)
        return None
```

#### 2. 清晰度计算

```python
def calculate_image_sharpness(image_path):
    """
    计算图像清晰度（使用Laplacian方差）。
    值越大表示图像越清晰。
    """
    try:
        img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
        if img is None:
            return 0.0
        laplacian_var = cv2.Laplacian(img, cv2.CV_64F).var()
        return laplacian_var
    except Exception as e:
        print(f"WARNING: Failed to calculate sharpness for {image_path}: {e}", flush=True)
        return 0.0
```

#### 3. 智能去重流程

```python
def deduplicate_by_similarity(screenshot_list, similarity_threshold=5, min_group_interval=3):
    """
    基于图像相似度的智能去重。
    
    策略：
    1. 使用感知哈希计算图像相似度
    2. 相似的图像（哈希距离 < threshold）归为一组
    3. 每组保留清晰度最高的图像
    4. 确保相邻保留的图像之间至少间隔min_group_interval个场景
    
    Args:
        screenshot_list: 截图文件路径列表（已按场景顺序排序）
        similarity_threshold: 哈希距离阈值，越小越严格（推荐3-8）
        min_group_interval: 同一组内最小场景间隔，避免过度去重
    
    Returns:
        去重后的截图列表
    """
    # 1. 计算所有图像的哈希值和清晰度
    image_data = []
    for i, img_path in enumerate(screenshot_list):
        phash = calculate_perceptual_hash(img_path)
        sharpness = calculate_image_sharpness(img_path)
        scene_num = get_scene_number_from_path(img_path)
        
        if phash is not None:
            image_data.append({
                'path': img_path,
                'hash': phash,
                'sharpness': sharpness,
                'scene_num': scene_num,
                'index': i
            })
    
    # 2. 动态分组：相似的图像归为一组
    groups = []
    used = set()
    
    for i, img_data in enumerate(image_data):
        if i in used:
            continue
        
        current_group = [img_data]
        used.add(i)
        
        # 查找相似的图像
        for j in range(i + 1, len(image_data)):
            if j in used:
                continue
            
            hash_distance = img_data['hash'] - image_data[j]['hash']
            
            if hash_distance <= similarity_threshold:
                current_group.append(image_data[j])
                used.add(j)
        
        groups.append(current_group)
    
    # 3. 从每组中选择最清晰的图像
    selected_images = []
    for group in groups:
        group_sorted = sorted(group, key=lambda x: x['sharpness'], reverse=True)
        best_image = group_sorted[0]
        selected_images.append(best_image)
    
    # 4. 按原始顺序排序
    selected_images.sort(key=lambda x: x['index'])
    
    # 5. 应用最小间隔过滤
    final_images = []
    last_scene_num = -999
    
    for img_data in selected_images:
        scene_num = img_data['scene_num']
        
        if scene_num - last_scene_num >= min_group_interval:
            final_images.append(img_data['path'])
            last_scene_num = scene_num
    
    return final_images
```

### 参数说明

#### 1. similarity_threshold（相似度阈值）
- **类型**：整数
- **推荐值**：3-8
- **说明**：
  - 哈希距离阈值，越小越严格
  - 值为5表示哈希值差异≤5的图像被视为相似
  - 较小值（3-4）：更严格，只有非常相似的图像才会归为一组
  - 较大值（7-8）：更宽松，稍有差异的图像也会归为一组

#### 2. min_group_interval（最小场景间隔）
- **类型**：整数
- **推荐值**：2-5
- **说明**：
  - 保留的截图之间最小场景间隔
  - 值为3表示相邻保留的截图至少间隔3个场景
  - 避免保留过于密集的截图
  - 防止过度去重导致重要内容丢失

#### 3. scene_detection_threshold（场景检测阈值）
- **类型**：浮点数
- **推荐值**：5-30
- **说明**：
  - PySceneDetect的ContentDetector阈值
  - 较低值（5-10）：更敏感，检测更多场景变化
  - 较高值（25-30）：不敏感，只检测明显的场景切换

## 技术细节

### 感知哈希算法
- 使用pHash（Perceptual Hash）
- 对图像进行DCT变换，提取低频信息
- 对旋转、缩放、亮度变化具有鲁棒性
- 哈希距离（Hamming距离）表示图像差异

### 清晰度计算
- 使用Laplacian算子
- 计算图像梯度的方差
- 方差越大，图像边缘越清晰

### 性能优化
- 哈希计算复杂度：O(n)，n为图像数量
- 相似度比较复杂度：O(n²)，但通过early stopping优化
- 对于100张图像，处理时间约5-10秒

## 总结

新的去重方案通过以下方式解决了原有问题：

1. **动态分组** → 解决"重要页面被丢失"
2. **相似度计算** → 解决"仍有重复内容"
3. **清晰度选择** → 确保保留最佳质量的截图
4. **最小间隔** → 平衡去重效果和内容完整性

预期效果：
- ✅ 减少重复截图
- ✅ 保留重要页面
- ✅ 提高截图质量
