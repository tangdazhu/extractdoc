### 4.3 AI驱动的HTML内容提取

#### 4.3.1 功能概述

为了应对不同网站复杂多变的HTML结构，系统引入了**AI驱动的HTML内容提取**能力。通过大语言模型（LLM）直接理解网页语义，相比传统的CSS选择器 + 正则表达式方案具备以下特点：

- **通用性强**：无需为每个网站单独维护选择器；
- **语义理解**：可以准确识别章节标题（例如“第3-11章”）；
- **容错性好**：对嵌套复杂或改版后的HTML仍然有效；
- **完整提取**：章节、图片、元信息均可一次性产出结构化结果。

传统方案的主要局限：

- 依赖手工维护，无法覆盖所有网站场景；
- 面对复杂嵌套结构或动态渲染容易失效；
- 对HTML结构变动极其敏感，维护成本高；
- 章节识别常基于简单正则，容易遗漏。

#### 4.3.2 工作原理

流程如下：

```python
# 1. 请求HTML并清理无用标签
response = requests.get(url, headers=self.headers, timeout=self.timeout)
soup = BeautifulSoup(response.text, "html.parser")
for tag in soup(["script", "style", "nav", "footer", "header", "aside", "iframe", "noscript"]):
    tag.decompose()

cleaned_html = soup.prettify()

# 2. 构建提示词，引导LLM输出结构化JSON
prompt = """请分析以下HTML内容，提取文章的结构化信息。\n要求：\n1. 识别文章标题、作者、发布时间\n2. 提取所有章节标题和内容（包括“第X章”标题）\n3. 提取文章中的图片URL\n4. 返回JSON格式"""

messages = [
    {"role": "system", "content": "你是一名资深的数据抽取工程师"},
    {"role": "user", "content": f"{prompt}\n\nHTML:\n{cleaned_html}"}
]

# 3. 调用LLM并解析返回JSON
response = self.llm_client.chat(messages=messages)
result = json.loads(response["output"])  # 统一结构体
```

#### 4.3.5 性能与成本控制

- **HTML长度限制**：对清理后的HTML按配置 `web_extraction.max_html_length` 截断，避免超过模型Token限制；
- **标签清理**：移除脚本、导航、广告等噪音标签，降低Token消耗；
- **温度设置**：使用低温度输出，确保JSON格式稳定；
- **缓存策略**：结合 `cache/web_extraction/` 缓存，重复请求直接返回缓存结果。

## 5. Playwright浏览器渲染

### 5.1 为什么选择Playwright？

#### Playwright vs Selenium

| 特性 | Playwright ⭐ | Selenium |
|------|-------------|----------|
| **性能** | 2-3倍更快 | 较慢 |
| **API设计** | 现代化、异步 | 传统、同步 |
| **自动等待** | ✅ 内置智能等待 | ❌ 需手动配置 |
| **浏览器管理** | ✅ 自动下载和管理 | ❌ 需手动配置Driver |
| **网络拦截** | ✅ 原生支持 | ❌ 需额外工具 |
| **跨浏览器** | Chrome/Firefox/Safari | Chrome/Firefox |
| **维护状态** | 🔥 Microsoft活跃维护 | 活跃 |

### 5.2 支持的网站

| 网站 | 域名 | 渲染方式 | 特殊处理 |
|------|------|---------|---------|
| 微信公众号 | mp.weixin.qq.com | HTTP请求 | 提取正文 |
| 头条 | toutiao.com | Playwright | 移除推荐 |
| 知乎 | zhihu.com | Playwright | 等待.RichText |
| CSDN | csdn.net | Playwright | 自动渲染 |
| 掘金 | juejin.cn | Playwright | 自动渲染 |
| B站 | bilibili.com | Playwright | 自动渲染 |

### 5.3 实现代码

```python
def _get_html_with_playwright(self, url: str) -> str:
    """使用Playwright获取渲染后的HTML"""
    with sync_playwright() as p:
        # 根据配置选择浏览器类型
        if self.browser_type == "firefox":
            browser = p.firefox.launch(headless=self.headless)
        elif self.browser_type == "webkit":
            browser = p.webkit.launch(headless=self.headless)
        else:  # chromium (默认)
            browser = p.chromium.launch(headless=self.headless)
        
        page = browser.new_page(user_agent=self.headers["User-Agent"])
        page.set_default_timeout(self.page_load_timeout)
        page.goto(url, wait_until="domcontentloaded")
        
        # 等待网络空闲
        if self.wait_for_network_idle:
            page.wait_for_load_state("networkidle", timeout=10000)
        
        # 针对头条：移除推荐内容
        if "toutiao.com" in url:
            page.evaluate("""
                () => {
                    const recommendSelectors = [
                        '[class*="recommend"]',
                        '[class*="related"]',
                        '[class*="feed-card"]'
                    ];
                    recommendSelectors.forEach(selector => {
                        document.querySelectorAll(selector).forEach(el => {
                            const article = document.querySelector('article');
                            if (article && !article.contains(el)) {
                                el.remove();
                            }
                        });
                    });
                }
            """)
        
        html = page.content()
        browser.close()
        return html
```

## 6. 多来源文章自动总结与PPT生成方案

### 6.1 需求目标

- **输入范围**：支持本地多格式文档（PDF、DOCX、TXT、PPT 等）与网络文章链接并行处理。
- **输出结果**：
  - 分层的文本摘要（全文总结、精简摘要、关键要点列表）。
  - 自动化的 PPT 结构（封面、目录、重点内容、结论页）。
- **模型约束**：统一对接阿里云通义千问（Qwen）；所有提示词、参数通过配置管理。

### 6.2 系统架构

- **表现层**：Django 模板 + 静态资源，提供上传、配置、结果展示，页面交互沿用 `文档生成` 模块。
- **服务层**：Django/DRF 编排任务，必要时引入 FastAPI 子服务封装千问调用；结合 Celery + Redis 实现异步处理与重试。
- **模型层**：通义千问负责摘要、要点提炼、PPT文本生成；提示词模板详见第8节。
- **数据层**：PostgreSQL 记录任务与元数据，对象存储（MinIO/S3）保存原文与生成结果。

### 6.3 核心流程

1. **内容采集**：
   - 本地上传：表单校验格式/大小；
   - 网络抓取：`requests` + `BeautifulSoup` 按 `robots.txt` 规则抽取正文；
   - OCR：`paddleocr` + `opencv-python` 处理扫描件。
2. **文本预处理**：`PyMuPDF`、`pdfplumber`、`python-docx`、`openpyxl`、`python-pptx` 统一清洗结构；封装章节识别、段落切分。
3. **语义分析与生成**：多批次调用千问生成摘要、关键词、综合分析；结合本地 TF-IDF 预筛选关键词。
4. **PPT生成**：
   - 模板管理：基于 `python-pptx` 预置主题；
   - 内容填充：封面、目录、章节、数据引用、结论；
   - 导出：默认 PPTX，可选 `reportlab`/`docx2pdf` 转 PDF。
5. **任务管理**：Celery 队列调度、状态追踪、告警与通知。

### 6.4 安全与运维

- **权限控制**：Django Auth / JWT；上传文件病毒扫描；对象存储按用户隔离。
- **日志与监控**：`utils.logger.setup_logger()` 输出结构化日志到 `logs/`；Prometheus + Grafana 监控千问接口、OCR耗时、PPT生成耗时。
- **部署建议**：Docker 化部署，CI/CD 自动发布；定期备份 PostgreSQL 与对象存储。
- **迭代计划**：阶段化扩展多文档整合、模板管理、智能配图、行业化模板。

## 8. 提示词模板系统设计

### 8.1 设计目标与原则

- **解耦提示词与业务逻辑**：所有提示词转移到 `extract_web/prompts/templates/`，通过 YAML 配置；业务代码只负责选择与填充变量。
- **多租户隔离**：系统模板与用户自定义模板分别存放，用户修改不影响系统默认。
- **易扩展 & 版本管理**：模板带有 `metadata`（名称、描述、类型、版本、作者），支持后续版本化与新模板类型。

### 8.2 目录结构

```
extract_web/
├── prompts/
│   ├── templates/                # 系统默认模板（技术文章、架构文档、教程等）
│   ├── user_templates/{user_id}/ # 用户自定义模板目录（gitignore）
│   ├── template_manager.py       # 模板加载、缓存、保存
│   └── schema.py                 # 模板数据结构定义
└── ...
```

### 8.3 模板格式示例

- **系统提示词**：使用 YAML `system_prompt` 字段定义硬性规则（例如：必须保留章节完整性、要求层级缩进、禁止生成赘述）。
- **用户提示词模板**：`user_prompt_template` 支持变量占位（如 `batch_index`、`total_batches`、`batch_content`、`dedup_hint`），用于分批投喂文段。
- **变量定义**：`variables` 列表声明变量名、类型、是否必填与默认值，模板管理器负责校验。

### 8.4 模板管理流程

1. 业务代码读取配置确定模板类型（如 `technical_article`、`architecture_doc`）。
2. `template_manager.py` 加载系统模板，合并用户覆盖项，生成最终提示词。
3. `schema.py` 校验字段完整性，确保模板结构符合约束。
4. Web/API 层提供模板查看、复制、修改、另存、恢复默认等能力。

### 8.5 与文档提取流程的衔接

- `WebContentExtractor` / `ai_document_analyzer` 在调用千问时，先通过模板管理器构造提示词，再结合运行时变量生成最终请求。
- 模板体系与本章节的多来源总结方案联动，保证不同文档类型能够快速切换提示词策略。
- 后续可在配置中记录模板版本号，便于追踪模型输出差异与调优效果。

```python
def _get_referer_for_image(self, img_url: str) -> str:
    """根据图片URL智能设置Referer"""
    
    # 微信图片
    if "mmbiz.qpic.cn" in img_url or "mmbiz.qlogo.cn" in img_url:
        return "https://mp.weixin.qq.com/"
    
    # 头条图片
    if "toutiaoimg.com" in img_url or "toutiaostatic.com" in img_url:
        return "https://www.toutiao.com/"
    
    # 知乎图片
    if "zhimg.com" in img_url:
        return "https://www.zhihu.com/"
    
    # CSDN图片
    if "csdnimg.cn" in img_url:
        return "https://blog.csdn.net/"
    
    # 掘金图片
    if "juejin.cn" in img_url or "juejin.im" in img_url:
        return "https://juejin.cn/"
    
    # B站图片
    if "bilibili.com" in img_url or "hdslb.com" in img_url:
        return "https://www.bilibili.com/"
    
    # 默认：使用图片所在域名
    parsed = urlparse(img_url)
    if parsed.scheme and parsed.netloc:
        return f"{parsed.scheme}://{parsed.netloc}/"
    
    return "https://www.toutiao.com/"
```

#### 6.1.3 图片下载流程

```python
def _download_image(self, img_url: str) -> Optional[Path]:
    """下载图片到临时文件"""
    
    # 1. 智能设置Referer
    referer = self._get_referer_for_image(img_url)
    
    # 2. 添加请求头
    headers = {
        "User-Agent": "Mozilla/5.0 ...",
        "Referer": referer  # 动态设置
    }
    
    # 3. 下载图片
    response = requests.get(img_url, headers=headers, timeout=10)
    response.raise_for_status()
    
    # 4. 验证图片
    img_data = BytesIO(response.content)
    pil_img = PILImage.open(img_data)
    
    # 5. 智能提取扩展名
    suffix = self._extract_image_extension(img_url, pil_img.format)
    
    # 6. 保存到临时文件
    temp_file = tempfile.NamedTemporaryFile(delete=False, suffix=suffix)
    pil_img.save(temp_file.name)
    temp_file.close()
    
    return Path(temp_file.name)
```

### 6.2 扩展名智能提取

**方法**: `_extract_image_extension(img_url: str, pil_format: str) -> str`

**三层检测机制**:

```python
def _extract_image_extension(self, img_url: str, pil_format: str = None) -> str:
    """智能提取图片扩展名"""
    
    # 方法1: 优先使用PIL检测到的格式
    if pil_format:
        format_map = {
            'JPEG': '.jpg',
            'PNG': '.png',
            'GIF': '.gif',
            'WEBP': '.webp',
            'BMP': '.bmp',
            'TIFF': '.tiff'
        }
        ext = format_map.get(pil_format.upper())
        if ext:
            return ext
    
    # 方法2: 从URL路径提取（去除查询参数）
    parsed = urlparse(img_url)
    path = parsed.path
    
    # 匹配常见图片扩展名（忽略大小写）
    match = re.search(r'\.(jpg|jpeg|png|gif|webp|bmp|tiff|svg)(?:[?#]|$)', 
                     path, re.IGNORECASE)
    if match:
        return '.' + match.group(1).lower()
    
    # 方法3: 检查文件名中是否包含扩展名（不在末尾的情况）
    match = re.search(r'\.(jpg|jpeg|png|gif|webp|bmp|tiff)', 
                     path, re.IGNORECASE)
    if match:
        return '.' + match.group(1).lower()
    
    # 默认返回.jpg
    return '.jpg'
```

```python
class URLToPPTConverter:
    def convert(self, url: str, output_path: str) -> Dict:
        """从URL生成PPT"""
        
        # 1. 提取网页内容
        article = self.content_extractor.extract_from_url(url)
        
        # 2. AI分析生成PPT结构
        ppt_structure = self.content_analyzer.analyze_content(article)
        
        # 3. 创建PPT
        self._create_ppt(ppt_structure, output_path, article['images'])
        
        return result

    def _create_ppt(self, ppt_structure: Dict, output_path: str, images: list):
        """创建PPT文件"""
        
        # 选择生成器
        if self.style == "style_b":
            generator = AcademicStylePPTGenerator()
        else:
            generator = BusinessStylePPTGenerator()
        
        # 1. 创建封面页
        generator.create_cover_slide(
            title=ppt_structure["cover"]["title"],
            subtitle=ppt_structure["cover"]["subtitle"]
        )
        
        # 2. 创建目录页
        catalog_items = []
        for i, slide_data in enumerate(ppt_structure["slides"]):
            catalog_items.append({
                "number": f"{i+1:02d}",
                "title": slide_data["title"]
            })
        generator.create_catalog_slide(catalog_items)
        
        # 3. 创建内容页
        image_index = 0
        for slide_data in ppt_structure["slides"]:
            title = slide_data["title"]
            points = slide_data["points"]
            
            # 检查是否有图片
            has_image = self._slide_contains_image_marker(slide_data)
            
            if has_image and image_index < len(images):
                # 下载图片
                image_path = self._download_image(images[image_index])
                if image_path:
                    generator.create_picture_slide(
                        title=title,
                        image_path=str(image_path)
                    )
                image_index += 1
            else:
                # 创建文本页
                generator.create_content_slide(title, points)
        
        # 4. 保存PPT
        generator.save(output_path)
```
