# 三列卡片和时间线布局修复

**修复日期**：2025-10-23  
**问题来源**：用户反馈三个新的布局问题

---

## 问题描述

### 问题1：三列卡片文本冲突 ❌

**现象**（截图1）：
- 三张卡片的文本内容过长，互相重叠
- 卡片内容超出卡片边界
- 文本居中对齐导致长文本显示不佳

**原因**：
- `card_content_max_chars = 30`（硬编码）
- 文本对齐方式：`PP_ALIGN.CENTER`（居中）
- 无行间距设置，文本密集

### 问题2：时间线页面内容为空 ❌

**现象**（截图2）：
- 页面标题："3. Agent 未来：五大假设"
- 页面内容完全为空
- 日志显示：`解析结果: 0个时间线项目`

**原因**：
- 时间线解析逻辑要求主要点不以"  "开头
- 如果所有内容都是子要点（以"  "开头），解析失败
- 返回空列表，导致页面无内容

### 问题3：时间线节点冲出页面 ❌

**现象**（截图3）：
- 5个时间线节点垂直排列
- 最后的节点超出页面底部
- 节点间距固定，无法适应不同数量

**原因**：
- `item_height = 1.2`（硬编码）
- `start_y = 2.0`（硬编码）
- 5项 × 1.2英寸 = 6英寸，超出可用高度
- 字体大小固定，不随节点数量调整

---

## 根本原因分析

### 违反配置化原则

**硬编码参数**：
```python
# ❌ 三列卡片
card_width = 3.5
card_gap = 0.5
card_content_max_chars = 30

# ❌ 时间线
item_height = 1.2
start_y = 2.0
max_items = 6  # 有默认值
```

### 缺少动态调整机制

**问题**：
- 三列卡片：文本长度固定，无法适应不同内容
- 时间线解析：逻辑过于严格，无法处理特殊格式
- 时间线布局：高度固定，无法适应不同项目数量

---

## 解决方案

### 修复1：配置化三列卡片参数 ✅

**文件**：`config/application.yaml`

**添加配置**：
```yaml
three_column:
  enabled: true
  card_style: true
  max_cards: 3                   # 最多显示卡片数
  card_width: 3.5                # 卡片宽度（英寸）
  card_gap: 0.5                  # 卡片间隙（英寸）
  card_title_font_size: 20       # 卡片标题字体大小
  card_content_font_size: 12     # 卡片内容字体大小
  card_content_max_chars: 80     # 卡片内容最大字符数
```

**代码修改**：
```python
# ✅ 从配置读取
max_cards = config.get("ppt_generation.layout_types.three_column.max_cards")
card_width = config.get("ppt_generation.layout_types.three_column.card_width")
card_gap = config.get("ppt_generation.layout_types.three_column.card_gap")
card_title_font_size = config.get("ppt_generation.layout_types.three_column.card_title_font_size")
card_content_font_size = config.get("ppt_generation.layout_types.three_column.card_content_font_size")
card_content_max_chars = config.get("ppt_generation.layout_types.three_column.card_content_max_chars")

# 智能截断
if len(content) > card_content_max_chars:
    truncate_pos = int(card_content_max_chars * 0.9)
    for j in range(truncate_pos, max(truncate_pos - 10, 0), -1):
        if j < len(content) and content[j] in '。，、；':
            content = content[:j+1]
            break
    else:
        content = content[:truncate_pos] + "..."

# 文本左对齐 + 行间距
card_content_text.paragraphs[0].alignment = PP_ALIGN.LEFT
card_content_text.paragraphs[0].line_spacing = 1.2
```

**效果**：
- ✅ 字符限制：30 → 80字符
- ✅ 文本对齐：居中 → 左对齐
- ✅ 行间距：无 → 1.2倍
- ✅ 文本不再重叠

### 修复2：时间线解析逻辑增强 ✅

**文件**：`content_parser.py`

**修改前**：
```python
# ❌ 只能解析标准格式
for line in lines:
    if not line.startswith("  "):
        # 主要点
        current_item = {"title": line.strip("- ").strip(), "content": ""}
    elif current_item:
        # 子要点
        current_item["content"] += " " + line.strip("  - ").strip()

# 如果没有主要点，items为空
return items  # 可能为空列表
```

**修改后**：
```python
# ✅ 增加容错处理
for line in lines:
    if not line.startswith("  "):
        current_item = {"title": line.strip("- ").strip(), "content": ""}
    elif current_item:
        current_item["content"] += " " + line.strip("  - ").strip()

# 如果没有解析到项目，尝试将所有行作为独立项目
if not items:
    logger.warning(f"时间线解析失败，尝试将每行作为独立项目")
    for line in lines:
        clean_line = line.strip("- ").strip()
        if clean_line:
            items.append({"title": clean_line, "content": ""})

# 移除硬编码默认值
max_items = config.get("ppt_generation.layout_types.timeline.max_items")
```

**效果**：
- ✅ 解析成功率提升
- ✅ 特殊格式也能处理
- ✅ 不再返回空列表

### 修复3：时间线动态调整算法 ✅

**文件**：`config/application.yaml`

**添加配置**：
```yaml
timeline:
  enabled: true
  vertical: true
  max_items: 6                   # 最多显示项目数
  base_item_height: 1.2          # 基础项目高度（英寸）
  min_item_height: 0.8           # 最小项目高度（英寸）
  available_height: 5.5          # 可用高度（英寸）
  start_y: 2.0                   # 起始Y坐标（英寸）
  title_font_size: 18            # 标题字体大小
  content_font_size: 14          # 内容字体大小
  content_max_chars: 60          # 内容最大字符数
```

**代码修改**：
```python
# ✅ 从配置读取参数
max_items = config.get("ppt_generation.layout_types.timeline.max_items")
base_item_height = config.get("ppt_generation.layout_types.timeline.base_item_height")
min_item_height = config.get("ppt_generation.layout_types.timeline.min_item_height")
available_height = config.get("ppt_generation.layout_types.timeline.available_height")
start_y = config.get("ppt_generation.layout_types.timeline.start_y")
title_font_size = config.get("ppt_generation.layout_types.timeline.title_font_size")
content_font_size = config.get("ppt_generation.layout_types.timeline.content_font_size")
content_max_chars = config.get("ppt_generation.layout_types.timeline.content_max_chars")

items_to_show = timeline_items[:max_items]
item_count = len(items_to_show)

# 动态计算项目高度
if item_count > 0:
    calculated_height = available_height / item_count
    item_height = max(min_item_height, min(calculated_height, base_item_height))
else:
    item_height = base_item_height

# 根据高度调整字体大小
if item_height < 1.0:
    title_font_size = int(title_font_size * 0.85)
    content_font_size = int(content_font_size * 0.85)
    content_max_chars = int(content_max_chars * 0.8)

# 动态高度内容框
box_height = item_height * 0.8
content_box = slide.shapes.add_shape(
    MSO_SHAPE.ROUNDED_RECTANGLE,
    Inches(line_x + 0.5), Inches(y_pos - 0.1),
    Inches(9), Inches(box_height)
)
```

**动态调整逻辑**：

| 项目数 | 计算高度 | 实际高度 | 字体调整 |
|--------|----------|----------|----------|
| 3项    | 1.83英寸 | 1.2英寸  | 18pt/14pt |
| 4项    | 1.38英寸 | 1.2英寸  | 18pt/14pt |
| 5项    | 1.1英寸  | 1.1英寸  | 18pt/14pt |
| 6项    | 0.92英寸 | 0.92英寸 | 15pt/12pt |

**效果**：
- ✅ 5项高度：1.1英寸（自动缩小）
- ✅ 总高度：5.5英寸（在页面内）
- ✅ 字体自动调整
- ✅ 所有节点都在页面内
