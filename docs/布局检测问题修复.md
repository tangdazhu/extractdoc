# 布局检测问题修复

> **修复时间**：2025-10-22 下午  
> **版本**：v2.1

---

## 问题描述

### 问题1：所有页面都被检测为左右对比布局

**现象**：
```
INFO 检测到对比布局: 3. 第 2 章 AI 原生应用的关键要素
INFO 检测到对比布局: 5. 第 4 章 上下文工程
INFO 检测到对比布局: 6. 第 5 章 AI 工具
INFO 检测到对比布局: 7. 第 6 章 AI 网关
...
```

**根本原因**：
关键词检测过于宽泛，`COMPARISON_KEYWORDS`包含"AI"，导致所有带"AI"的标题都被误判为对比布局。

```python
# ❌ 错误的关键词定义
COMPARISON_KEYWORDS = [
    "vs", "对比", "比较", "传统", "AI", "新旧", "前后",  # "AI"太宽泛！
    "优势", "劣势", "差异", "区别", "对照"
]
```

---

### 问题2：右侧大段文字没有重点

**现象**：
截图2显示右侧内容为大段密集文字，没有：
- 分段
- Bullet符号
- 层次结构
- 关键点提取

**根本原因**：
内容解析器简单地平均分割，没有：
- 限制文本长度
- 智能分句
- 提取关键点

---

## 修复方案

### 修复1：优化关键词检测逻辑

#### 改进1：移除过于宽泛的关键词

```python
# ✅ 修复后
COMPARISON_KEYWORDS = [
    "vs", "对比", "比较", "新旧", "前后",
    "优势", "劣势", "差异", "区别", "对照",
    "传统 vs", "传统与", "相比"  # 改为组合关键词
]
```

**变化**：
- 移除"AI"单独关键词
- 移除"传统"单独关键词
- 改为组合关键词"传统 vs"、"传统与"

#### 改进2：两级检测机制

```python
def _has_comparison(self, text: str, lines: List[str]) -> bool:
    """检测是否包含对比关系"""
    # 强对比关键词（优先级最高）
    strong_keywords = ["vs", "对比", "比较", "差异", "区别", "优势", "劣势"]
    if any(kw in text for kw in strong_keywords):
        return True
    
    # 检查是否有明显的对比结构
    if "传统" in text and ("AI" in text or "新" in text):
        return True
    
    return False
```

**逻辑**：
1. 优先检测强对比关键词（vs、对比等）
2. 其次检测组合结构（传统+AI）
3. 避免单一关键词误判

---

### 修复2：优化内容解析

#### 改进1：限制文本长度

```python
# 从配置读取
max_text_length = config.get("ppt_generation.layout_types.two_column.max_text_length", 60)

# 限制每个要点长度
if len(clean_line) > max_text_length:
    # 尝试在句号处分割
    sentences = clean_line.split("。")
    for sent in sentences[:2]:  # 最多取前2句
        if sent.strip():
            all_points.append(sent.strip() + "。")
else:
    all_points.append(clean_line)
```

**效果**：
- 超过60字的要点自动分句
- 最多取前2句
- 避免大段文字

#### 改进2：智能分句

**分句规则**：
1. 按句号"。"分割
2. 取前2句作为关键点
3. 保留句号结尾

**示例**：
```
输入：
"本章从开发一个简单的Agent开始，介绍了标准的智能体开发流程以及业内主流的智能体开发范式，并围绕工作流模式、对话模式进行了详细介绍。"

输出：
- "本章从开发一个简单的Agent开始，介绍了标准的智能体开发流程以及业内主流的智能体开发范式。"
- "并围绕工作流模式、对话模式进行了详细介绍。"
```

### 修复3：添加配置控制

#### 配置文件更新

```yaml
# config/application.yaml
ppt_generation:
  layout_types:
    auto_detect: true                # 是否启用自动布局检测
    two_column:
      enabled: true
      split_ratio: 0.5
      max_text_length: 60            # 每个要点最大长度
```

#### 转换器中使用

```python
# 检查是否启用自动布局检测
auto_detect = config.get("ppt_generation.layout_types.auto_detect", True)

if auto_detect:
    # 自动检测布局类型
    layout_type = self.layout_detector.detect_layout_type(content_dict)
    self._create_slide_by_layout(generator, layout_type, content_dict)
else:
    # 使用默认布局
    generator.create_content_slide(title, points)
```

## 配置说明

### 关键配置项

```yaml
# 自动布局检测开关
ppt_generation.layout_types.auto_detect: true

# 文本长度限制
ppt_generation.layout_types.two_column.max_text_length: 60
```

### 调整建议

**如果要点太长**：
```yaml
max_text_length: 40  # 减小到40字
```

**如果要点太短**：
```yaml
max_text_length: 80  # 增大到80字
```

**禁用自动检测**：
```yaml
auto_detect: false  # 全部使用bullet_list
```
