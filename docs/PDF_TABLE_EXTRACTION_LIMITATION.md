# PDF表格提取限制

## 问题描述

pdfplumber在提取某些复杂表格时存在严重bug,导致内容错位和丢失。

## 具体案例

### 原始PDF表格(正确)

| 版本 | 内容 |
|------|------|
| 0.1 | 首次发布: LLM 基础、开发参考架构... |
| 0.5 | Refined by Allen Huang |
| 0.6 | 增加 LLM 模型和应用安全内容 |
| 1.0 | 增加 LLM 基础细节 |

### pdfplumber提取结果(错误)

```python
table = [
    ['版本\n0.1', '内容\nLLM\n首次发布：...', ...],  # 表头+第一行
    ['0.5', 'Refined by Allen Huang', ...],        # 正确
    ['0.6', 'LLM', ...],                            # ❌ 只有关键词
    ['1.0', '增加 模型和应用安全内容\nLLM', ...],  # ❌ 内容错误
]
```

### 问题分析

1. **0.6行**: 内容"增加 LLM 模型和应用安全内容"被分成两部分
   - 第2行只提取到"LLM"
   - 第3行提取到"增加 模型和应用安全内容\nLLM"(这是0.6行的内容)

2. **1.0行**: 真实内容"增加 LLM 基础细节"完全丢失
   - 被替换为0.6行的内容

## 当前解决方案

### 部分修复(已实现)

```python
# 智能修复: 如果某行只有"LLM",从下一行合并内容
if str(row[1]).strip() == 'LLM':
    if next_row[1].startswith('增加'):
        # 合并: "增加 模型..." → "增加 LLM 模型..."
        next_content = next_content.replace('\nLLM', '')
        parts = next_content.split(' ', 1)
        row[1] = f"{parts[0]} LLM {parts[1]}"
```

**效果**:
- ✅ 0.6行修复为: "增加 LLM 模型和应用安全内容"
- ❌ 1.0行仍然错误: 内容丢失,无法恢复

### 限制

**无法从错误数据中恢复正确数据!**

- 0.6行的内容被成功修复(因为内容在下一行)
- 1.0行的内容完全丢失(pdfplumber没有提取到)

## 最终结论

**pdfplumber的表格提取存在严重bug,导致部分行的内容完全丢失。**

### 修复结果

| 行 | 原始(正确) | PDF提取(错误) | 修复后 | 状态 |
|----|-----------|--------------|--------|------|
| 0.1 | 首次发布: LLM 基础... | LLM\n首次发布... | 首次发布: LLM 基础... | ✅ 已修复 |
| 0.5 | Refined by Allen Huang | Refined by Allen Huang | Refined by Allen Huang | ✅ 正确 |
| 0.6 | 增加 LLM 模型和应用安全内容 | LLM | 增加 LLM 模型和应用安全内容 | ✅ 已修复 |
| 1.0 | 增加 LLM 基础细节 | 增加 模型和应用安全内容\nLLM | 增加 LLM 模型和应用安全内容 | ❌ 无法修复(内容丢失) |

### 为什么1.0行无法修复?

**PDF提取时,1.0行的真实内容"增加 LLM 基础细节"完全没有被提取到!**

提取到的是0.6行的内容"增加 模型和应用安全内容\nLLM",导致:
1. 0.6行被修复为"增加 LLM 模型和应用安全内容" ✅
2. 1.0行也被修复为"增加 LLM 模型和应用安全内容" ❌ (这是0.6的内容!)

**检测到重复后**: 我们知道1.0行的内容是错误的,但无法推断出正确的内容,因为:
- 正确内容"增加 LLM 基础细节"在PDF提取时就丢失了
- 我们只能从错误的数据中工作
- 不能hardcode特定的修复(违反规则)
