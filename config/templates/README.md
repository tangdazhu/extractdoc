# PPT 模板说明

## 模板列表

### 1. 现代商务风格 (business_template.pptx)

**视觉特点**:
- 🎨 **深蓝渐变背景**: 从深蓝(#0D1B3E)到中蓝(#19376D)的垂直渐变
- ✨ **装饰元素**: 
  - 左下角浅蓝色圆形装饰(半透明)
  - 右上角金色圆形装饰(半透明)
  - 内容页顶部蓝色装饰条
- 📝 **文字颜色**: 白色标题 + 浅灰白副标题/正文
- 🎯 **适用场景**: 商务汇报、项目展示、企业宣传

**配色方案**:
- 主色: 深蓝色 (#0D1B3E, #19376D)
- 强调色: 天蓝色 (#3498DB)
- 点缀色: 金色 (#F39C12)
- 文字: 白色 (#FFFFFF) + 浅灰白 (#ECF0F1)

### 2. 学术报告风格 (academic_template.pptx)

**视觉特点**:
- 🎨 **深灰蓝渐变背景**: 从深灰蓝(#2C3E50)到中灰蓝(#34495E)的垂直渐变
- ✨ **装饰元素**: 
  - 左侧学术红竖条(全高)
  - 底部学术红横条
  - 右上角浅灰装饰块
  - 内容页标题下方红色装饰线
- 📝 **文字颜色**: 白色标题 + 浅灰白正文
- 🎯 **适用场景**: 学术论文、研究报告、科研汇报

**配色方案**:
- 主色: 深灰蓝 (#2C3E50, #34495E)
- 强调色: 学术红 (#E74C3C)
- 辅助色: 浅灰 (#95A5A6)
- 文字: 白色 (#FFFFFF) + 浅灰白 (#ECF0F1)

## 使用说明

### 自动应用模板

系统会根据配置文件自动加载对应的模板:

```yaml
# config.yaml
ppt_templates:
  business:
    template_path: "config/templates/business_template.pptx"
  academic:
    template_path: "config/templates/academic_template.pptx"
```

### 模板特性

1. **渐变背景**: 所有页面都有专业的渐变背景
2. **装饰元素**: 精心设计的装饰形状增强视觉效果
3. **统一配色**: 标题、正文、装饰元素颜色协调统一
4. **白色文字**: 在深色背景上清晰可读

### 重新生成模板

如需修改模板样式,编辑 `create_ppt_templates.py` 后运行:

```bash
cd config
python create_ppt_templates.py
```

## 设计理念

### 商务风格
- **专业**: 深蓝色传达信任和专业
- **现代**: 渐变背景和几何装饰展现现代感
- **清晰**: 高对比度确保信息清晰传达

### 学术风格
- **严谨**: 深灰蓝背景体现学术严谨性
- **专注**: 左侧红色竖条引导视线
- **专业**: 简洁的装饰线条突出学术专业性
