## 5. Playwright浏览器渲染

### 5.1 为什么选择Playwright？

#### Playwright vs Selenium

| 特性 | Playwright ⭐ | Selenium |
|------|-------------|----------|
| **性能** | 2-3倍更快 | 较慢 |
| **API设计** | 现代化、异步 | 传统、同步 |
| **自动等待** | ✅ 内置智能等待 | ❌ 需手动配置 |
| **浏览器管理** | ✅ 自动下载和管理 | ❌ 需手动配置Driver |
| **网络拦截** | ✅ 原生支持 | ❌ 需额外工具 |
| **跨浏览器** | Chrome/Firefox/Safari | Chrome/Firefox |
| **维护状态** | 🔥 Microsoft活跃维护 | 活跃 |

### 5.2 支持的网站

| 网站 | 域名 | 渲染方式 | 特殊处理 |
|------|------|---------|---------|
| 微信公众号 | mp.weixin.qq.com | HTTP请求 | 提取正文 |
| 头条 | toutiao.com | Playwright | 移除推荐 |
| 知乎 | zhihu.com | Playwright | 等待.RichText |
| CSDN | csdn.net | Playwright | 自动渲染 |
| 掘金 | juejin.cn | Playwright | 自动渲染 |
| B站 | bilibili.com | Playwright | 自动渲染 |

### 5.3 实现代码

```python
def _get_html_with_playwright(self, url: str) -> str:
    """使用Playwright获取渲染后的HTML"""
    with sync_playwright() as p:
        # 根据配置选择浏览器类型
        if self.browser_type == "firefox":
            browser = p.firefox.launch(headless=self.headless)
        elif self.browser_type == "webkit":
            browser = p.webkit.launch(headless=self.headless)
        else:  # chromium (默认)
            browser = p.chromium.launch(headless=self.headless)
        
        page = browser.new_page(user_agent=self.headers["User-Agent"])
        page.set_default_timeout(self.page_load_timeout)
        page.goto(url, wait_until="domcontentloaded")
        
        # 等待网络空闲
        if self.wait_for_network_idle:
            page.wait_for_load_state("networkidle", timeout=10000)
        
        # 针对头条：移除推荐内容
        if "toutiao.com" in url:
            page.evaluate("""
                () => {
                    const recommendSelectors = [
                        '[class*="recommend"]',
                        '[class*="related"]',
                        '[class*="feed-card"]'
                    ];
                    recommendSelectors.forEach(selector => {
                        document.querySelectorAll(selector).forEach(el => {
                            const article = document.querySelector('article');
                            if (article && !article.contains(el)) {
                                el.remove();
                            }
                        });
                    });
                }
            """)
        
        html = page.content()
        browser.close()
        return html
```

```python
def _get_referer_for_image(self, img_url: str) -> str:
    """根据图片URL智能设置Referer"""
    
    # 微信图片
    if "mmbiz.qpic.cn" in img_url or "mmbiz.qlogo.cn" in img_url:
        return "https://mp.weixin.qq.com/"
    
    # 头条图片
    if "toutiaoimg.com" in img_url or "toutiaostatic.com" in img_url:
        return "https://www.toutiao.com/"
    
    # 知乎图片
    if "zhimg.com" in img_url:
        return "https://www.zhihu.com/"
    
    # CSDN图片
    if "csdnimg.cn" in img_url:
        return "https://blog.csdn.net/"
    
    # 掘金图片
    if "juejin.cn" in img_url or "juejin.im" in img_url:
        return "https://juejin.cn/"
    
    # B站图片
    if "bilibili.com" in img_url or "hdslb.com" in img_url:
        return "https://www.bilibili.com/"
    
    # 默认：使用图片所在域名
    parsed = urlparse(img_url)
    if parsed.scheme and parsed.netloc:
        return f"{parsed.scheme}://{parsed.netloc}/"
    
    return "https://www.toutiao.com/"
```

#### 6.1.3 图片下载流程

```python
def _download_image(self, img_url: str) -> Optional[Path]:
    """下载图片到临时文件"""
    
    # 1. 智能设置Referer
    referer = self._get_referer_for_image(img_url)
    
    # 2. 添加请求头
    headers = {
        "User-Agent": "Mozilla/5.0 ...",
        "Referer": referer  # 动态设置
    }
    
    # 3. 下载图片
    response = requests.get(img_url, headers=headers, timeout=10)
    response.raise_for_status()
    
    # 4. 验证图片
    img_data = BytesIO(response.content)
    pil_img = PILImage.open(img_data)
    
    # 5. 智能提取扩展名
    suffix = self._extract_image_extension(img_url, pil_img.format)
    
    # 6. 保存到临时文件
    temp_file = tempfile.NamedTemporaryFile(delete=False, suffix=suffix)
    pil_img.save(temp_file.name)
    temp_file.close()
    
    return Path(temp_file.name)
```

### 6.2 扩展名智能提取

**方法**: `_extract_image_extension(img_url: str, pil_format: str) -> str`

**三层检测机制**:

```python
def _extract_image_extension(self, img_url: str, pil_format: str = None) -> str:
    """智能提取图片扩展名"""
    
    # 方法1: 优先使用PIL检测到的格式
    if pil_format:
        format_map = {
            'JPEG': '.jpg',
            'PNG': '.png',
            'GIF': '.gif',
            'WEBP': '.webp',
            'BMP': '.bmp',
            'TIFF': '.tiff'
        }
        ext = format_map.get(pil_format.upper())
        if ext:
            return ext
    
    # 方法2: 从URL路径提取（去除查询参数）
    parsed = urlparse(img_url)
    path = parsed.path
    
    # 匹配常见图片扩展名（忽略大小写）
    match = re.search(r'\.(jpg|jpeg|png|gif|webp|bmp|tiff|svg)(?:[?#]|$)', 
                     path, re.IGNORECASE)
    if match:
        return '.' + match.group(1).lower()
    
    # 方法3: 检查文件名中是否包含扩展名（不在末尾的情况）
    match = re.search(r'\.(jpg|jpeg|png|gif|webp|bmp|tiff)', 
                     path, re.IGNORECASE)
    if match:
        return '.' + match.group(1).lower()
    
    # 默认返回.jpg
    return '.jpg'
```

```python
    def convert(self, url: str, output_path: str) -> Dict:
        """从URL生成PPT"""
        
        # 1. 提取网页内容
        article = self.content_extractor.extract_from_url(url)
        
        # 2. AI分析生成PPT结构
        ppt_structure = self.content_analyzer.analyze_content(article)
        
        # 3. 创建PPT
        self._create_ppt(ppt_structure, output_path, article['images'])
        
        return result

    def _create_ppt(self, ppt_structure: Dict, output_path: str, images: list):
        """创建PPT文件"""
        
        # 选择生成器
        if self.style == "style_b":
            generator = AcademicStylePPTGenerator()
        else:
            generator = BusinessStylePPTGenerator()
        
        # 1. 创建封面页
        generator.create_cover_slide(
            title=ppt_structure["cover"]["title"],
            subtitle=ppt_structure["cover"]["subtitle"]
        )
        
        # 2. 创建目录页
        catalog_items = []
        for i, slide_data in enumerate(ppt_structure["slides"]):
            catalog_items.append({
                "number": f"{i+1:02d}",
                "title": slide_data["title"]
            })
        generator.create_catalog_slide(catalog_items)
        
        # 3. 创建内容页
        image_index = 0
        for slide_data in ppt_structure["slides"]:
            title = slide_data["title"]
            points = slide_data["points"]
            
            # 检查是否有图片
            has_image = self._slide_contains_image_marker(slide_data)
            
            if has_image and image_index < len(images):
                # 下载图片
                image_path = self._download_image(images[image_index])
                if image_path:
                    generator.create_picture_slide(
                        title=title,
                        image_path=str(image_path)
                    )
                image_index += 1
            else:
                # 创建文本页
                generator.create_content_slide(title, points)
        
        # 4. 保存PPT
        generator.save(output_path)
```

## 9. 部署与运维

### 9.1 环境要求

```bash
# Python版本
Python 3.12+

# 操作系统
Windows / Linux / macOS

# 依赖管理
Poetry (推荐) 或 pip
```

### 9.2 安装步骤

```bash
# 1. 克隆项目
git clone <repository_url>
cd extract_doc

# 2. 安装依赖
pip install -r requirements.txt

# 3. 安装Playwright浏览器
playwright install chromium

# 4. 配置环境变量
# 创建 .env 文件
DASHSCOPE_API_KEY=your_api_key_here

# 5. 运行项目
python manage.py runserver
```

### 9.3 配置文件

**主配置文件**: `config/application.yaml`

```yaml
# AI配置
ai_document_analysis:
  model: "qwen3-max"
  temperature: 0.1
  max_tokens: 4000

# 网页提取配置
web_extraction:
  cache_dir: "cache/web_extraction"
  timeout: 30
  use_browser: true
  browser_type: "chromium"
  
# PPT生成配置
ppt_generation:
  styles:
    style_a:
      name: "简约商务风格"
      template_path: "config/templates/business_template.pptx"
```

### 9.4 日志系统

**日志目录**: `logs/`

**日志文件**:
- `app.log`: 应用主日志
- `error.log`: 错误日志
- `access.log`: 访问日志

**日志级别**:
- `DEBUG`: 详细调试信息
- `INFO`: 一般信息
- `WARNING`: 警告信息
- `ERROR`: 错误信息

### 9.5 缓存系统

**缓存目录**: `cache/web_extraction/`

**缓存策略**:
- 网页提取结果自动缓存
- 缓存文件以URL的MD5哈希命名
- 缓存永久有效（除非手动清除）

**清除缓存**:
```bash
# 清除所有缓存
rm -rf cache/web_extraction/*

# 清除特定URL缓存
# 在代码中调用
extractor.clear_cache(url)
```
