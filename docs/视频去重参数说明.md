# 视频去重参数详细说明

## 参数说明

### 1. 场景检测阈值 (Scene Detection Threshold)
- **范围**：5-30
- **默认值**：10.0
- **作用**：控制PySceneDetect检测场景变化的敏感度

#### 工作原理
- **值越小** → 越敏感 → 检测到更多场景 → 生成更多原始截图
- **值越大** → 不敏感 → 只检测明显变化 → 生成较少原始截图

#### 推荐值
- **PPT演示**：8-12
- **教学视频**：6-10
- **电影/动画**：15-25

#### 示例
```
阈值=5   → 检测到250个场景（非常敏感，微小变化都检测）
阈值=10  → 检测到103个场景（适中）
阈值=20  → 检测到45个场景（不敏感，只检测明显切换）
```

---

### 2. 相似度阈值 (Similarity Threshold)
- **范围**：1-20
- **推荐值**：4-8
- **默认值**：5
- **作用**：控制图像哈希距离阈值，决定哪些图像被视为"相似"

#### 工作原理
使用感知哈希（pHash）计算图像相似度：
- 两张图像的哈希距离 ≤ 阈值 → 归为同一组
- 哈希距离 > 阈值 → 归为不同组

#### 重要提示
⚠️ **值越小越严格，值越大越宽松！**

- **阈值=2**：只有几乎完全相同的图像才会归为一组（太严格）
- **阈值=5**：相似的图像归为一组（推荐）
- **阈值=10**：稍有相似就归为一组（太宽松）

#### 推荐值
- **渐进式PPT**：**5-7**（重要！不要设置为2）
- **标准PPT**：4-6
- **教学视频**：3-5

#### 实际效果对比
```
相似度阈值=2：
  103张原始 → 74组 → 去重效果差（只合并了29张）
  
相似度阈值=5：
  103张原始 → 40组 → 去重效果好（合并了63张）
  
相似度阈值=8：
  103张原始 → 25组 → 去重效果很好（合并了78张）
```

---

### 3. 最小场景间隔 (Min Group Interval)
- **范围**：1-10
- **推荐值**：2-4
- **默认值**：3
- **作用**：保留的截图之间必须至少间隔N个场景

#### 工作原理
在相似度分组之后，进行第二次过滤：
- 如果两张保留的截图场景间隔 < 阈值 → 跳过后一张
- 场景间隔 ≥ 阈值 → 保留

#### 重要提示
⚠️ **这个参数控制最终输出的密度！**

- **间隔=1**：几乎不过滤，保留所有分组后的图像
- **间隔=3**：相邻保留的截图至少间隔3个场景
- **间隔=5**：输出更稀疏，可能丢失重要内容

#### 推荐值
- **渐进式PPT**：**2-3**（不要设置为1）
- **标准PPT**：3-4
- **教学视频**：2-3

#### 实际效果对比
```
最小间隔=1：
  74组 → 74张最终输出（几乎不过滤）
  
最小间隔=2：
  74组 → 45张最终输出（过滤了29张密集的）
  
最小间隔=3：
  74组 → 30张最终输出（过滤了44张密集的）
```

## 参数组合建议

### 场景1：渐进式PPT动画（你的情况）
**问题**：PPT有逐步显示的动画，产生很多相似但内容逐渐增加的截图

**推荐参数**：
```
场景检测阈值：9-10
相似度阈值：5-6    ← 关键！不要设置为2
最小场景间隔：2-3   ← 关键！不要设置为1
```

**预期效果**：
```
103张原始 → 35-45组 → 25-35张最终输出
```

**特点**：页面切换明显，没有复杂动画

**推荐参数**：

```
相似度阈值：4-5
最小场景间隔：3-4
```

**预期效果**：
```
100张原始 → 30-40组 → 20-30张最终输出
```

**特点**：板书逐步添加，需要捕捉每个重要步骤

**推荐参数**：
```
场景检测阈值：7-8
相似度阈值：3-4
最小场景间隔：2
```

**预期效果**：
```
200张原始 → 80-100组 → 50-70张最终输出
```

### 场景4：截图太多时
**问题**：输出截图数量过多

**调整方向**：
```
↑ 提高场景检测阈值（减少原始截图）
↑ 提高相似度阈值（合并更多相似图像）
↑ 提高最小间隔（增加输出稀疏度）
```

**示例调整**：
```
场景检测阈值：12-15
相似度阈值：6-8
最小场景间隔：4-5
```

---

### 场景5：截图太少/丢失重要内容时
**问题**：输出截图数量过少，丢失重要页面

**调整方向**：
```
↓ 降低场景检测阈值（增加原始截图）
↓ 降低相似度阈值（减少合并）
↓ 降低最小间隔（允许更密集的输出）
```

**示例调整**：
```
场景检测阈值：7-8
相似度阈值：3-4
最小场景间隔：1-2
```

## 调试技巧

### 1. 查看日志
关键日志信息：
```
Original: 103        ← 原始截图数量
After grouping: 74   ← 相似度分组后的组数
Final: 74            ← 最小间隔过滤后的最终数量
```

### 2. 分析去重效果

#### 情况A：After grouping ≈ Original
```
Original: 103, After grouping: 95, Final: 60
```
**问题**：相似度阈值太严格，几乎没有合并
**解决**：提高相似度阈值（5→7）

#### 情况B：After grouping = Final
```
Original: 103, After grouping: 74, Final: 74
```
**问题**：最小间隔没有起作用（间隔太小）
**解决**：提高最小场景间隔（1→3）

#### 情况C：理想情况
```
Original: 103, After grouping: 40, Final: 30
```
**效果**：相似度合并了63张，间隔过滤了10张

### 3. 查看分组详情
日志中会显示每组的详细信息：
```
INFO: Group 5: 3 similar images [scene_012(d:0.65), scene_013(d:0.68), scene_014(d:0.72)], 
      selected scene_014 (density: 0.720)
```

这表示：
- 场景12、13、14被归为一组（相似）
- 选择了内容密度最高的场景14（0.72）

## 你的问题诊断

根据你的日志：
```
Original: 103, After grouping: 74, Final: 74
```

**诊断**：
1. ❌ 相似度阈值=2 太严格，只合并了29张（103-74=29）
2. ❌ 最小场景间隔=1 太小，没有过滤任何图像（74=74）

**建议修改**：
```

最小场景间隔：1 → 2 或 3
```

**预期改善**：
```

```

## 总结

**关键要点**：
1. ⚠️ **相似度阈值不是越小越好**！值越小越严格，合并越少
2. ⚠️ **最小间隔不是越小越好**！值太小会保留过多密集截图
